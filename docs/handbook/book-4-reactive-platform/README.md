# Book 4 — Reactive Platform

Book 4 explains reactive SPP applications from first principles and then traces the current runtime implementation.

## Chapters

1. Reactive UI: why it exists
2. LiveComponent mental model
3. LiveComponent state and hydration/dehydration
4. LiveComponent lifecycle hooks
5. LiveComponent actions, validation, rendering, and downloads
6. LiveComponent integrity and server-side state
7. SPPLive architecture and engine selection
8. SPPLive transports and failure boundaries
9. SPPUX runtime bootstrap, mounting, and assets
10. Choosing between server-rendered pages, LiveComponent, SPPLive, and SPPUX

## Source baseline

Reactive chapters are synchronized to the changed SPP implementation supplied for the V3 rewrite. Exact lifecycle, engine-selection, asset, and mount behavior must be verified against that implementation when future versions change.
