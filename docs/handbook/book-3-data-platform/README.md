# Book 3 — Data and Reporting Platform

This book teaches SPP's data architecture from application-level persistence down to driver/compiler and reporting internals.

## Chapters

1. SPPDB from the Application Developer's View
2. Connections, Drivers, and Connection Reuse
3. SQL Compiler Architecture
4. Dialects and Driver-Specific Compilation
5. Entities, Queries, and Repositories
6. Transactions and Error Boundaries
7. Schema Evolution and Migrations
8. XDB Architecture
9. Reporting as a Data Pipeline
10. SPPReport Driver and External Database Architecture
11. Schema Introspection and Validation
12. Report Security, Query Construction, and Operational Design

## Source baseline

The changed SPPDB and SPPReport implementations supplied for this V3 work are the source authority for current behavior. Documentation must not describe capabilities stronger than the implementation demonstrates.
