## Maintenance cycle

```text
SPP source change
      ↓
identify affected subsystem
      ↓
update canonical teaching chapter
      ↓
update reference/source map
      ↓
update runnable lab
      ↓
re-check diagrams and links
      ↓
record evidence status
```

The audit layer is intentionally separate from the teaching chapters so that learners are not burdened with maintenance mechanics while maintainers have an explicit release checklist.
