06. Forms & Validation

SPP provides an enterprise-grade form and validation system designed around a single core invariant: write your validation logic once, and validate everywhere. A unified 4-way validation pipeline bridges Server-Side PHP, Browser Native HTML5, SPP-UX Client JS, and Drishyam LiveComponents.

1. Quickstart: The Fluent Builder API

Build validated forms programmatically in PHP with a clean, chainable syntax via Form:

use SPPMod\SPPView\Form;

$form = Form::create('registration_form', '/register')
    ->addText('username', 'Username', ['required' => true, 'min' => 3])
    ->addEmail('email', 'Email Address', ['required' => true])
    ->addPassword('password', 'Password', ['required' => true, 'min' => 8])
    ->addSubmit('submit_btn', 'Create Account')
    ->build();

echo $form->render();

2. Declarative Form Definitions in YAML

In SPP, forms can be defined declaratively in YAML under etc/apps/<AppName>/forms/<name>.yml:

# etc/apps/school1/forms/student_enrollment.yml
form:
  name: student_enrollment_form
  title: "Student Enrollment"
  action: "/students/enroll"
  method: post
  id: "student_enrollment_form"

fields:
  student_name:
    type: text
    label: "Full Name"
    rules: "required|min:3|max:100"
    col: 6

  email:
    type: email
    label: "Parent Email"
    rules: "required|email"
    col: 6

  admission_code:
    type: text
    label: "Admission Code"
    rules: "required|admission_no"
    col: 6

  parent_pan:
    type: text
    label: "Parent PAN Card"
    rules: "required|pan"
    col: 6

  submit_btn:
    type: submit
    value: "Enroll Student"
    class: "btn btn-primary"

To render the YAML form in your controller:

use SPPMod\SPPView\ViewFormBuilder;

$form = ViewFormBuilder::fromYaml('forms/student_enrollment.yml');
echo $form->render();

3. Universal Custom Validators (Rule)

Extend \SPPMod\SPPView\Validation\Rule to author custom validators that automatically execute on both PHP backend and browser frontend:

namespace App\School1\Rules;

use SPPMod\SPPView\Validation\Rule;

class AdmissionNoRule extends Rule
{
    public function __construct(protected string $pattern = '^[A-Z]{3}-[0-9]{4}-[A-Z]{2}$') {}

    public function passes(string $attribute, mixed $value, array $data = []): bool
    {
        if ($value === null || $value === '') return true;
        return (bool)preg_match('/' . $this->pattern . '/', (string)$value);
    }

    public function message(string $attribute): string
    {
        return ucfirst($attribute) . " must follow the format ABC-YYYY-XX.";
    }

    public function clientRule(string $attribute): array
    {
        return [
            'pattern' => $this->pattern,
            'minlength' => 11,
            'maxlength' => 11,
            'data-rule' => 'admission_no',
            'data-msg' => $this->message($attribute),
        ];
    }
}

4. Declarative YAML Validator Registration (validators.yml)

Register validators declaratively in etc/apps/<AppName>/validators.yml with zero PHP bootstrapping:

# etc/apps/school1/validators.yml
validators:
  admission_no:
    pattern: '^[A-Z]{3}-[0-9]{4}-[A-Z]{2}$'
    message: 'Admission number must follow format ABC-YYYY-XX.'
    minlength: 11
    maxlength: 11
    data-rule: 'admission_no'

  curriculum_track:
    in: ['cbse', 'icse', 'state', 'ib']
    message: 'Curriculum track must be cbse, icse, state, or ib.'

  exam_score:
    range: [0, 100]
    message: 'Score must be between 0 and 100.'

5. Built-in Universal & Country-Specific ID Validators

SPP comes pre-equipped with high-performance validators for Indian and global ID standards:

  • pan: Indian Income Tax PAN Card (10 chars, regex format: [A-Z]{5}[0-9]{4}[A-Z]{1})
  • aadhaar: 12-Digit UIDAI Aadhaar Number
  • gstin: 15-Digit Goods & Services Tax ID
  • ifsc: Bank IFSC Routing Code
  • pincode: 6-Digit Indian Postal Code
  • indmobile: 10-Digit Mobile Number (starts with 6-9)
  • passwordstrength: Enterprise Security Password
  • creditcard: Luhn Check Credit Card Number

6. Direct Entity Data Binding

Hydrate forms and entities bidirectionally with active record models:

// Hydrate form from database:
$student = Student::find(42);
$form->bind($student);
echo $form->render();

// Process form submission:
$student = new Student();
$form->fill($student);
if ($form->isValid()) {
    $student->save();
} else {
    $errors = $form->getErrors();
}

7. CLI Scaffolding Tools

Generate production-ready forms and validation rules with native CLI commands:

# Scaffold a YAML form definition:
php spp.php make:form StudentRegistration --app=school1

# Scaffold a custom validator rule class and auto-register in validators.yml:
php spp.php make:rule AdmissionCode --app=school1 --pattern="^[A-Z]{3}-[0-9]{4}$" --min=8 --max=8

8. SPP Developer Studio (sppdev) Form & Validation Studio

For visual and low-code workflows, SPP integrates a complete Form & Validation Studio inside sppdev (accessible at /sppdev):

  • Visual Drag & Drop Form Builder: Dedicated palette elements for PAN Card (pan), Aadhaar Card (aadhaar), GSTIN (gstin), IFSC Code (ifsc), and PIN Code (pincode).
  • Validation Inspector (Tab 4): One-click toggles for standard rules and built-in enterprise IDs, dynamic application custom rule checkboxes from validators.yml, min/max length constraints, and a quick-action + New Custom Rule button.
  • Custom Validators & Rule Studio: Comprehensive suite tab displaying all registered rules, metrics, an interactive Live Rule Tester for typing test values and getting real-time regex feedback, and a visual rule generator to scaffold new PHP Rule classes and update validators.yml without touching code.
  • 1-Click Code Studio Deep-Linking: Saving a rule with a PHP class or clicking 💻 Code on any rule card instantly opens Code Studio (#coder?file=...) with that class file focused and ready for editing.

9. Plain HTML Forms with YAML ID Binding (@sppform_bind)

Write pure, bespoke HTML templates and bind your declarative Form YAML schema with a single Blade directive:

<!-- In your Blade view: -->
<form id="student_enrollment_form" method="POST" action="/students/enroll" @sppform_bind('student_enrollment')>
    <div class="mb-3">
        <label for="first_name">First Name</label>
        <input type="text" id="first_name" name="first_name" class="form-control" placeholder="Aarav">
    </div>

    <div class="mb-3">
        <label for="email">Parent Email</label>
        <input type="email" id="email" name="email" class="form-control" placeholder="parent@example.com">
    </div>

    <button type="submit" class="btn btn-primary">Submit Application</button>
</form>

In your ViewController, validate the request in one line:

public function enroll()
{
    $validation = $this->validateForm('student_enrollment');
    if ($validation->fails()) {
        return $this->json(['errors' => $validation->errors()], 422);
    }

    // Process valid submission...
}

10. Visual Forms & Rule Studio in Drishyam Studio (#pages)

Within Drishyam Studio (/sppdev/#pages), manage forms visually on the live WYSIWYG canvas:

  • 📝 Forms Palette Tab: Inspect all YAML Form Manifests and registered Validator Rules side-by-side with canvas components.
  • ➕ Insert Form: 1-click synthesis of semantic HTML forms directly onto the canvas with @sppform_bind(...) pre-configured.
  • 🔗 Bind Form: Select any <form> on the canvas and bind it to a YAML manifest in 1 click.
  • WYSIWYG Inspector: Instant dropdowns to select Form YAML schemas for forms, and quick-attach validator rules to any selected input element.
