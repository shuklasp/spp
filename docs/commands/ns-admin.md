## NAME

**admin** - Administration dashboard and backend utilities

## PURPOSE

The `admin` namespace is a logical grouping of SPP CLI commands related to Administration dashboard and backend utilities. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying admin subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `admin` namespace, the CLI router isolates execution to specific modules and classes optimized for Administration dashboard and backend utilities. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man admin:<subcommand>`.
