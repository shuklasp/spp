## NAME

**i18n** - Internationalization export/import

## PURPOSE

The `i18n` namespace is a logical grouping of SPP CLI commands related to Internationalization export/import. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying i18n subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `i18n` namespace, the CLI router isolates execution to specific modules and classes optimized for Internationalization export/import. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man i18n:<subcommand>`.
