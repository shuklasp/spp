## NAME

**audit** - System audit logs and lineages

## PURPOSE

The `audit` namespace is a logical grouping of SPP CLI commands related to System audit logs and lineages. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying audit subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `audit` namespace, the CLI router isolates execution to specific modules and classes optimized for System audit logs and lineages. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man audit:<subcommand>`.
