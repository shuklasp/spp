`verify:sovereignty` - Validates complete stack self-containment/zero external links

`php spp.php verify:sovereignty`

# PURPOSE

Audits the absolute air-gapped sovereign compliance of the SPP Framework stack to ensure zero reliance on third-party CDNs or external network dependencies.
