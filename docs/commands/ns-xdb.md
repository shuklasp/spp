## NAME

**xdb** - SPPXDB XML database shell and queries

## PURPOSE

The `xdb` namespace is a logical grouping of SPP CLI commands related to SPPXDB XML database shell and queries. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying xdb subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `xdb` namespace, the CLI router isolates execution to specific modules and classes optimized for SPPXDB XML database shell and queries. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man xdb:<subcommand>`.
