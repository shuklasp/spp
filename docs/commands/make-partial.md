## `make:partial`

**Description**: Scaffold a new external view partial template (HTML/PHP/JS)

### Synopsis
```bash
php spp.php make:partial [OPTIONS]
```

### Extended Usage
```text
Usage: php spp.php make:partial <PartialName.html|.php|.js> [--app=AppName]

```
