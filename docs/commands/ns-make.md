## NAME

**make** - Code generators and scaffolders

## PURPOSE

The `make` namespace is a logical grouping of SPP CLI commands related to Code generators and scaffolders. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying make subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `make` namespace, the CLI router isolates execution to specific modules and classes optimized for Code generators and scaffolders. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man make:<subcommand>`.
