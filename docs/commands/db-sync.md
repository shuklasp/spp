## `db:sync`

**Purpose**: Synchronize data between two database adapters (e.g. MySQL to XDB)

### Synopsis
```bash
php spp.php db:sync [OPTIONS]
```

### Extended Usage
```text
Usage: php spp.php db:sync --from=[engine:table] --to=[engine:table]

```
