## NAME

**theme** - Theme adapter switching

## PURPOSE

The `theme` namespace is a logical grouping of SPP CLI commands related to Theme adapter switching. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying theme subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `theme` namespace, the CLI router isolates execution to specific modules and classes optimized for Theme adapter switching. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man theme:<subcommand>`.
