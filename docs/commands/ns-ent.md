## NAME

**ent** - SPP Entity management and querying

## PURPOSE

The `ent` namespace is a logical grouping of SPP CLI commands related to SPP Entity management and querying. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying ent subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `ent` namespace, the CLI router isolates execution to specific modules and classes optimized for SPP Entity management and querying. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man ent:<subcommand>`.
