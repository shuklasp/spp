## NAME

**docs** - Documentation generation and parsing

## PURPOSE

The `docs` namespace is a logical grouping of SPP CLI commands related to Documentation generation and parsing. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying docs subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `docs` namespace, the CLI router isolates execution to specific modules and classes optimized for Documentation generation and parsing. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man docs:<subcommand>`.
