## NAME

**bridge** - Language bridges and polyglot adapters

## PURPOSE

The `bridge` namespace is a logical grouping of SPP CLI commands related to Language bridges and polyglot adapters. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying bridge subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `bridge` namespace, the CLI router isolates execution to specific modules and classes optimized for Language bridges and polyglot adapters. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man bridge:<subcommand>`.
