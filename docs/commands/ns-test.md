## NAME

**test** - Parikshak Evolutionary Testing suite

## PURPOSE

The `test` namespace is a logical grouping of SPP CLI commands related to Parikshak Evolutionary Testing suite. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying test subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `test` namespace, the CLI router isolates execution to specific modules and classes optimized for Parikshak Evolutionary Testing suite. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man test:<subcommand>`.
