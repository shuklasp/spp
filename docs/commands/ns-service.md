## NAME

**service** - Service layer and dependency injection

## PURPOSE

The `service` namespace is a logical grouping of SPP CLI commands related to Service layer and dependency injection. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying service subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `service` namespace, the CLI router isolates execution to specific modules and classes optimized for Service layer and dependency injection. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man service:<subcommand>`.
