## NAME

**storage** - Filesystem and storage sync tools

## PURPOSE

The `storage` namespace is a logical grouping of SPP CLI commands related to Filesystem and storage sync tools. This namespace provides a suite of administrative and operational tools specifically designed to interact with the underlying storage subsystems of the framework.

## UNDER THE HOOD ACTIVITY

When invoking commands within the `storage` namespace, the CLI router isolates execution to specific modules and classes optimized for Filesystem and storage sync tools. This modular architectural grouping prevents command collisions and ensures that each subsystem operates within its dedicated execution context.

To view the exhaustive details, options, and deep functionality of any specific command within this group, execute `php spp.php man storage:<subcommand>`.
