# Welcome to SPPDocs

This is the natively integrated SPP Markdown Documentation Reader!

It runs purely on a LAMP stack (PHP + Apache), completely replacing the need for an external Node.js server. 
It uses HTMX for blazing fast SPA-like navigation without full page reloads.

Try navigating to the [Getting Started](/sppdocs/docs/getting-started) guide to see it in action!
