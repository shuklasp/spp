# Book 1 — Foundations

This book starts from the assumption that the reader may know PHP but has never used a framework.

## Learning contract

Every chapter follows:

**Problem → Plain PHP → General framework idea → SPP → Build → Test → Break → Diagnose → Source trace → Architectural choice**

## Chapters

1. What Happens When You Open a Website?
2. Why Frameworks Were Invented
3. Frameworks in Context: Laravel, Symfony, Django, Rails, ASP.NET Core, and SPP
4. MVC from First Principles
5. The HTTP Request/Response Lifecycle
6. Containers, Dependency Injection, `bind()`, and `singleton()`
7. Services, Business Logic, and Application Boundaries
8. Routing Before SPP
9. `pages.yml` and Page-Oriented Routing
10. Attribute and Code-Oriented Routing
11. CLI Routing and Scaffolding
12. API and Live Routing Paradigms
13. Configuration, Settings, and Environment Separation
14. Application Contexts and the SPP Runtime
15. Where SPP Goes Beyond MVC

## Source baseline

This V3 branch is maintained as a source-synchronized handbook. Claims about current SPP behavior must be verified against the SPP implementation and tests for the documented source baseline.
