# 📱 Mobile Studio Pro: The Engineering Blueprint

Welcome to **Mobile Studio Pro**, the high-fidelity visual orchestration engine for cross-platform mobile applications. This is the "low-code" IDE that actually thinks like an engineer.

## 🏗️ Core Concepts

### 1. The Screen Architecture
In Mobile Studio Pro, an app is a collection of **Screens**. Each screen has its own recursive layout tree and local state.

### 2. Blueprints (High-Fidelity Templates)
Blueprints are pre-engineered architectural patterns. Instead of dragging a single button, you can apply a **Discovery Feed** or **Analytics Dashboard** blueprint.
*   **Precision Orchestration**: Blueprints enforce professional design standards (padding, alignment, hierarchy) out of the box.
*   **Dynamic Application**: Apply a blueprint to any screen to instantly scaffold its structure.

### 3. Atoms & Molecules (Components)
*   **Atoms**: Basic blocks like `Text`, `Button`, and `Image`.
*   **Organisms**: Complex widgets like `GridView`, `GlassPanel`, and `Carousel`.
*   **Interactive Assets**: Support for **Rive** (state-machine animations) and **Lottie** (JSON-based motion graphics).

---

## 🧠 The "Brain" (Logic & State)

### State Management
*   **Global Reactive State**: Define variables (e.g., `isLoggedIn`, `userName`) that persist across the entire app session.
*   **Reactive Binding**: Bind component properties to state variables. When the data changes, the UI updates instantly with zero boilerplate.

### Advanced Action Engine
Actions are orchestrated via a multi-step **Pipeline Builder**:
*   **Conditions**: Branch logic based on state values (e.g., `IF login_success == true`).
*   **Loops**: Iterate over dynamic data arrays (e.g., `FOR EACH item IN api_response`).
*   **Wait**: Implement delays and asynchronous wait-states for loading transitions.
*   **API Connectors**: Map REST API responses directly to your global state.

## ✨ AI Copilot & Logic Suite

### AI-Assisted Development
The unified **SPPAI Gateway** brings elite AI integration directly to your workbench:
*   **Model Registry**: Choose from a fleet of AI providers (Google, OpenAI, Claude, Anthropic) to assist your development.
*   **✨ AI Fix Logic**: One-click refactoring for your custom JavaScript snippets using specialized LLM logic drivers.

### FX Logic Library (Monaco)
Write complex business logic in the built-in **Monaco Editor** (the engine behind VS Code):
*   **Custom Functions (FX)**: Script dynamic behaviors that can be called from any Action Pipeline.
*   **State Access**: Full access to the global `appState` within your logic.

---

## 📂 Asset & Theme Orchestration

### Enterprise Asset Engine
*   **Hierarchical Management**: Organize media into logical namespaces.
*   **Native Paths**: Automated mapping of assets to platform-specific paths (Flutter/Dart).

### Design Token System
*   **Material Design 3**: Full compliance with MD3 standards.
*   **Multi-Theme Support**: Instantly switch between **Day**, **Dark**, and **Saffron** (Gold/Orange) modes with automatic contrast adjustment.

---

## 🚀 Deployment & Sync

### 1. PWA Sync
One-click synchronization to a **Progressive Web App** for instant browser-based testing.

### 2. Native Build
Compile your visual blueprint into production-ready **Flutter (Dart)** code, including full widget tree generation and event handler wiring.

---

## 🛠️ Typical Workflow
1.  **Orchestrate**: Create screens and apply architectural blueprints.
2.  **Define State**: Setup variables in the 'State' tab.
3.  **Code Logic**: Use the Monaco FX library to script complex behaviors.
4.  **Wire Up**: Build multi-step action pipelines.
5.  **AI Optimize**: Use the Copilot to refactor logic and generate screens.
6.  **Sync**: Hit 'Sync PWA' to see your creation live!
