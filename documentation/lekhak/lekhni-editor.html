Lekhni Editor: Enterprise WYSIWYG & Block Document Engine

Lekhni is the next-generation dual-mode visual publishing engine integrated directly within Lekhak CMS. It functions as both a rich block-based document editor and a raw source stream Monaco IDE, providing authors with offline database safety buffers, real-time revision timelines, and interactive document objects.

1. Interactive Block Elements & Slash Commands

Lekhni treats documents as structures of interactive components. Authors can invoke the floating Slash Menu by typing / on a new line or within any editable paragraph.

2. In-Depth Component Specifications

📊 Smart Formula Spreadsheet Grids

The Smart Grid creates a fully functional tabular cell framework inside the content.

  • Coordinate Architecture: Generates cells tagged with IDs from A1 to E5.
  • Formula Parsing Engine: Uses cell observers to evaluate mathematical formulas beginning with =. Supports scope-wide functions: SUM, AVERAGE, and PRODUCT.
  • Reactive Recalculation: Binds custom blur and focus listeners to coordinate cells, enabling a cascading recalculation chain.

☑️ Tasks Board Checklist

Allows list arrays to function as interactive trackers.

  • Dual-Mode Interaction: Readers and writers can toggle item checked states.
  • Visual Transitions: Checking a task applies interactive strike-through typography and transition animations dynamically.

📄 Adjustable PDF Document Frame

Provides embedded PDF viewing without leaving the page.

  • Rich Control Interface: Renders responsive slider controls inside the block header.
  • Dynamic Resizing: Listening to range sliders automatically applies corresponding pixel dimensions to the PDF iframe in real time.

🎴 Adaptive Multi-Image Gallery

Enables quick layout construction of media grids.

  • Drop-Zone Support: Seamlessly intercept files dragged into the editor and post them to the Lekhni media upload API.
  • CSS Flex Layout: Arranges multiple uploaded media items cleanly in responsive dark galleries.

3. Offline Safety & IndexedDB Buffer Architecture

Lekhni implements continuous data safety mechanisms to prevent data loss:

  • IndexedDB Safety Store: Mounts an IndexedDB database named LekhniEnterpriseStore.
  • State Restoration: Detects offline local snapshots upon load and displays an intuitive recovery modal.
  • Continuous Buffering: Keystrokes trigger debounced local commits of the current title and body layout.

4. Read-Mode Client Interactive Binders

To preserve complete block interactivity for public page views, Lekhak's node.blade.php registers key event loops at runtime:

  1. PDF Resize: Readers can adjust slide dimensions locally.
  2. Task checklist: Toggling checklist states operates dynamically.
  3. Spreadsheet formula engine: Recalculates cells immediately upon blurred input fields.
